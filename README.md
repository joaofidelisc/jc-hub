# JC Business

SaaS de "funcionário virtual" para pequenas empresas, utilizando Inteligência Artificial (IA) para atendimento, agendamentos, CRM e marketing.

## Funcionalidades Planejadas (MVP)
- **Onboarding por IA:** Captura de informações do negócio via chat.
- **Base de Conhecimento:** Construção estruturada dos dados da empresa.
- **Integração WhatsApp:** Recebimento e envio via Evolution API.
- **Atendimento Inteligente:** Agente que responde dúvidas e agenda serviços.
- **Agenda / CRM:** Gerenciamento de horários e pipeline de leads.
- **Dashboard:** Visão geral das métricas.

## Stack de Tecnologias
- **Frontend:** Next.js, Material UI, Tailwind CSS
- **Backend:** FastAPI, Python
- **Banco de Dados:** PostgreSQL (com pgvector)
- **Cache/Fila:** Redis
- **Infra:** Docker, Docker Compose
