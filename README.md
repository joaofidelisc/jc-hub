# JC Hub

SaaS de automação inteligente e central de atendimento utilizando Inteligência Artificial (IA) para suporte, agendamentos, CRM e marketing.

## Funcionalidades Planejadas (MVP)
- **Onboarding por IA:** Captura de informações do negócio via chat.
- **Base de Conhecimento:** Construção estruturada dos dados da empresa.
- **Integração Instagram & Messenger:** Recebimento e envio de mensagens e comentários.
- **Atendimento Inteligente:** Agente que responde dúvidas e engaja clientes 24/7.
- **Plataforma Central:** Gerenciamento unificado de atendimentos.
- **Dashboard:** Visão geral das métricas.

## Stack de Tecnologias
- **Frontend:** React (Vite), CSS Puro (Material Design 3)
- **Backend:** FastAPI, Python
- **Banco de Dados:** PostgreSQL (com pgvector)
- **Worker / Background Tasks:** Celery / RQ (Redis)
- **Cache/Fila:** Redis
- **Infra:** Docker, Docker Compose
